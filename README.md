# AI 灵感集 · AI 博主个人网站

一个苹果风格、色彩丰富的 AI 资源博主个人网站，用于展示你的 AI 产品、项目作品与精选资源。

## 使用

- 直接用 Chrome / Edge 双击 `index.html` 打开。
- 或者用服务器方式：双击 `启动网站.bat`（如果有）或运行 `python -m http.server 8000`。

## 自定义

- 修改站名与博主名：编辑 `index.html` 中的「AI 灵感集」「AI 探路者」等文字。
- 修改项目/产品内容：编辑 `index.html` 中的卡片文字。
- 替换配图：把新的图片放到 `images/` 目录，保持同名即可（当前为彩色矢量占位图）。
- 联系链接：修改页脚与导航中的链接地址。
- 切换配色：页面右上角「主题」按钮可在 明亮 / 沉稳 / 深色 / 苹果 / 商务 / 海蓝 / 科技 之间切换；也可在网址后加 `?theme=apple`、`?theme=tech` 等直接指定。

## 目录结构

```text
index.html      页面结构
css/style.css   样式（苹果风 + 彩色渐变）
js/app.js       交互（导航、滚动动画、项目筛选、订阅表单）
images/         配图（头像 + 项目 + 产品，均为 SVG 占位插画）
```
